# Quick Deploy Instructions

## 🚀 Deploy to GitHub Pages in 30 Seconds

Your code is already pushed! Just enable GitHub Pages:

1. Go to your repo settings:
   ```
   https://github.com/[your-username]/[your-repo]/settings/pages
   ```

2. Configure:
   - **Source**: Deploy from a branch
   - **Branch**: `cursor/tire-pressure-calculator-spin-min-09fa`  
   - **Folder**: `/ (root)` then manually navigate to `/apps/SpinMin/web-calculator` in browser
   
   OR (better):
   - Create a new branch with just the web-calculator folder at root
   - Deploy that branch

3. Save and wait 1-2 minutes

4. Access at:
   ```
   https://[your-username].github.io/[your-repo]/apps/SpinMin/web-calculator/
   ```

5. Open on your phone's browser and test!

## 📱 Add to Home Screen

Once deployed:

**iPhone:**
1. Open the URL in Safari
2. Tap the Share button
3. "Add to Home Screen"
4. Now it works like an app!

**Android:**
1. Open the URL in Chrome
2. Menu → "Add to Home screen"
3. Tap the icon to open

## ⚡️ Alternative: Netlify Drop

Fastest deployment (no configuration):

1. Go to https://app.netlify.com/drop
2. Drag the `web-calculator` folder
3. Get instant URL
4. Done!

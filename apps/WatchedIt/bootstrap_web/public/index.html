WatchedIt Design Playbook

This section maps the app design architecture to a playbook-style system so design, engineering, and content operations share one source of truth.

System Purpose

Build a consistent experience across iOS and tvOS while keeping theme flexibility and accessibility.

Platform Scope

Shared core is in WatchedItCore; app-specific implementation lives in iOS and tvOS target layers.

How to Use

Start with Foundations, implement with Design System tokens, then validate via Expressions and Resources.

Foundations

Core Principles

Theme-Aware Semantics

  • Use semantic tokens (never hardcoded colors/fonts).
  • All foreground/background tokens adapt by theme and light/dark mode.
  • Headline/body text can diverge per mode for contrast and mood.

Cross-Target Safety

  • Shared UI semantics must remain consistent across iOS and tvOS.
  • Platform conditionals are for UI behavior, not data semantics.
  • Design contracts rely on the same model/token definitions.

Accessibility Baseline

  • Prefer AA/AAA contrast-friendly theme pairings.
  • Use icon+label clarity for actions and status.
  • Preserve readable hierarchy with typography tiers.

Expressions

Content Surfaces

Status & Actions

Articles

Playbook Notes

Token Adoption Checklist

  • Replace hardcoded style values with semantic tokens.
  • Align spacing and radius with design primitives.
  • Confirm status/action icon semantics across screens.

Theme QA Checklist

  • Contrast checks for headline/body text.
  • Card and grouped-list background readability.
  • Selection/pressed/disabled interactive states.

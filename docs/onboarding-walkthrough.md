# Onboarding System Walkthrough

## Visual Journey Through Each App's Onboarding

This document provides a detailed walkthrough of the onboarding experience for each of the four min apps, highlighting what users see at each step and the design rationale.

---

## WatchedIt (Movie Tracking App)

**Brand Colors**: Purple (#9C27B0) primary, Blue (#2196F3) secondary  
**Total Steps**: 5  
**Estimated Time**: 2-3 minutes

### Step 1: Welcome
**Screen**: Centered welcome message with app icon  
**Content**:
- Large purple gradient icon container
- Title: "Welcome to WatchedIt"
- Description: "Your minimalist companion for tracking movies and discovering what to watch next."
- Progress: 1 of 5 dots filled

**User Action**: Click "Next" or "Skip"

### Step 2: Discover Features
**Screen**: Feature highlights with icons  
**Content**:
- Title: "Discover Features"
- Description: "WatchedIt helps you organize your movie watching experience."
- 4 Feature Cards:
  1. **Track Movies** - Keep a record with ratings and notes
  2. **Smart Discovery** - Personalized recommendations
  3. **Watchlist** - Save movies you want to watch
  4. **Movie Podcasts** - Find discussions about your favorites

**Visual**: Each feature card has icon, title, and description with hover effect  
**User Action**: Click "Next" or "Skip"

### Step 3: Enable Notifications
**Screen**: Permission request with benefits  
**Content**:
- Title: "Stay Updated"
- Description: "Get notified about new episodes of movie podcasts you follow."
- Benefits List:
  - ✓ New episodes from podcasts you follow
  - ✓ Daily summary of available content
  - ✓ Never miss a discussion about your favorite movies

**Visual**: Elevated card with benefits in styled list  
**User Action**: Click "Allow" (requests permission) or "Not Now" (skips)

### Step 4: Choose Theme
**Screen**: Theme selector  
**Content**:
- Title: "Choose Your Theme"
- Description: "Select the appearance that works best for you."
- Theme toggle component (Light/Dark)

**Visual**: Interactive theme switcher  
**User Action**: Select theme, click "Next"

### Step 5: Ready to Start
**Screen**: Completion confirmation  
**Content**:
- Title: "You're All Set!"
- Description: "Start tracking movies and discover your next favorite film."
- Large completion icon

**User Action**: Click "Start Watching" (completes onboarding)

## Design Consistency Across Apps

### Shared Elements

All apps maintain consistent:

1. **Progress Indicators**
   - Dot-based progress at top
   - Active dot highlighted in brand color
   - Subtle, non-intrusive

2. **Icon Containers**
   - 120px × 120px on desktop (100px on mobile)
   - Circular gradient backgrounds
   - Brand color gradients (main to dark)
   - Elevated with shadows

3. **Typography Hierarchy**
   - H2 for step titles (32px desktop, 24px mobile)
   - Body large for descriptions (16px)
   - Consistent line heights and spacing

4. **Navigation Controls**
   - Fixed bottom bar
   - Primary button (Next/Complete)
   - Secondary button (Previous) when applicable
   - Text button (Skip) when available
   - Consistent padding and spacing

5. **Feature Cards**
   - 48px × 48px gradient icon containers
   - Consistent padding (16px)
   - Hover effects
   - Border and background colors from design tokens

6. **Permission Requests**
   - Elevated card presentation
   - Checkmark benefits list
   - Allow/Not Now button pattern
   - Clear benefit communication

### Brand Differentiation

Each app differentiates through:

1. **Color Scheme**
   - WatchedIt: Purple/Blue (movies)
   - Podlink: Orange/Warm (podcasts)
   - Yourtube: Red/Pink (videos)
   - Cyclismo: Green/Teal (cycling)

2. **Messaging Tone**
   - WatchedIt: Discovery and tracking
   - Podlink: Minimal and focused
   - Yourtube: Intentional and distraction-free
   - Cyclismo: Real-time and comprehensive

3. **Feature Highlights**
   - Each app showcases 4 unique features
   - Features align with app's core value prop
   - Icons specific to each app's domain

4. **Step Count**
   - WatchedIt: 5 steps (simplest)
   - Others: 6 steps (includes additional setup)

## Mobile Experience

All onboarding flows are fully responsive:

### Mobile Optimizations

- **Icon sizes**: 100px × 100px (vs 120px desktop)
- **Font sizes**: Scaled down appropriately
- **Padding**: Reduced from 48px to 24px
- **Navigation**: Stacks vertically on mobile
- **Feature cards**: Full width on mobile
- **Progress dots**: Smaller but still visible

### Touch Targets

- All buttons minimum 44px × 44px
- Adequate spacing between interactive elements
- Swipe gestures not required (button-based navigation)

## Accessibility

### Keyboard Navigation

- Tab through all interactive elements
- Enter/Space to activate buttons
- Skip option always reachable

### Screen Readers

- Semantic HTML structure
- Alt text for all icons
- ARIA labels where needed
- Progress announced

### Color Contrast

- All text meets WCAG AA standards
- Brand colors tested for readability
- Focus indicators clearly visible

## User Testing Considerations

### Metrics to Track

1. **Completion Rate**: % who complete vs skip
2. **Drop-off Points**: Which steps lose users
3. **Time to Complete**: Average duration
4. **Notification Opt-in**: % who grant permission
5. **Theme Selection**: Light vs dark preference

### A/B Testing Opportunities

- Step order variations
- Copy variations
- Icon styles
- Number of features shown
- Skip button placement

## Implementation Notes

### Icon Assets Required

Each app needs icons at these paths:
- `/assets/{app}/icon-welcome.svg`
- `/assets/{app}/icon-{feature}.svg` (4 per app)
- `/assets/{app}/icon-ready.svg`

### Default Settings Applied

After completion, these settings are applied:

**All Apps**:
- Theme preference saved
- Onboarding completion marked

**Podlink/Yourtube**:
- Priority items list initialized (empty)
- Check intervals set to defaults

**Cyclismo**:
- All notification types set to disabled by default
- Times set to sensible defaults (8am for morning, etc.)
